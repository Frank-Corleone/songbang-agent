# 松绑 · 消除烦恼智能体

> 融合现代心理学与佛家思想的"情绪教练"系统提示词与方法论，从 12 本经典书籍中提炼而成。
> 版本 v1.0 · 2026-10

## 这是什么

一套可以直接粘贴给任何对话式 AI（ChatGPT / Claude / GLM / 文心 / 本地模型等）使用的**系统提示词 + 配套知识库**，把通用 AI 变成一个专业、温和、务实的烦恼分析教练「松绑」：

- 你向它讲述烦恼 → 它复述共情、识别情绪
- 给出 2—3 个根源假设（带证据与反证）
- 点出你的执着点（在抓住什么、抗拒什么）
- 心理学与佛学各给 1—2 个对治方法（注明书名与章节出处）
- 布置一个**今天就能做**的最小行动 + 晚间复盘问题
- 内置安全边界：危机信号自动转介专业帮助

## 快速开始（3 步）

1. 打开 [`03_智能体系统提示词.md`](03_智能体系统提示词.md)，复制代码块内全文；
2. 粘贴为 AI 的系统提示词（或本次对话的第一条消息，并注明"请严格按以上设定扮演"）；
3. 把第 1 节"用户背景"占位模板改成你自己的情况，然后直接分享你的烦恼。

## 方法论速览

**五步框架：觉（觉察）→ 名（命名）→ 溯（溯源）→ 松（松绑）→ 行（行动）**

| 模块 | 内容 |
|------|------|
| 六类根源 | R1 认知偏差 · R2 需求抓取 · R3 抗拒事实 · R4 关系边界 · R5 我执黏着 · R6 意义缺失 |
| 七类策略 | S1 稳定 · S2 觉察标记 · S3 解离重评 · S4 接纳通过 · S5 松绑执着 · S6 意义行动 · S7 人际慈悲 |
| 烦恼分级 | L0 波动 → L1 纠结 → L2 心结 → L3 危机（对应不同回应深度与转介规则） |
| 日常练习 | 每天约 10 分钟：三个呼吸锚点 + 触发时"停松观放" + 晚间省察五问；每周正念日 |
| 复盘指标 | 觉察率、情绪峰值、隔夜心结数、最小行动完成度、执着观察 |

详见 [`02_融合价值观与方法论.md`](02_融合价值观与方法论.md)。

## 设计原则

- **可执行、可复盘**：给选择不给命令，每次只布置一个当天能完成的最小行动；
- **不神秘化**：佛学概念一律转译为现代心理语言，默认不作宗教劝诱；
- **引用可溯源**：每条方法标注书名与章节出处；
- **安全优先**：不诊断疾病；出现自伤意念、持续两周以上情绪低落等信号时，停止常规分析并转介专业帮助（如全国心理援助热线 12356）。
